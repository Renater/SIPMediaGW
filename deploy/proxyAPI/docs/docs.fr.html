SIPMediaGW : connecteur de salle multi-plateforme

Présentation

Le connecteur de salle multi-plateforme SIPMediaGW est une passerelle d'interopérabilité permettant de relier dynamiquement des systèmes de visioconférence de salle de réunion à une plateforme de visioconférence compatible WebRTC comme :

  • Plateforme A
  • Plateforme B
  • Plateforme C
  • Plateforme D

Un équipement de salle (SIP ou compatible) peut ainsi établir un appel vers le connecteur afin de rejoindre une visioconférence, quel que soit son constructeur ou son environnement technique.

Comment utiliser les connecteurs de salle SIP

1

Créer la réunion (obligatoire)

Avant toute chose, vous devez créer votre réunion sur la plateforme cible :

  • Plateforme A
  • Plateforme B
  • Plateforme C
  • Plateforme D

Le connecteur de salle ne permet pas de créer ni démarrer une conférence.

Récupérer le bon identifiant de conférence

Selon la plateforme utilisée, l'identifiant à renseigner n'est pas le même :

  • Plateforme A et Plateforme C → il s'agit du nom de la conférence, c'est-à-dire la fin de l'URL de la conférence.
  • Plateforme B → il s'agit du code d'invitation fourni aux participants.
  • Plateforme D → il s'agit de l'URL complète d'accès à la visioconférence obtenue depuis l'outil de gestion.

Une fois cet identifiant récupéré, vous pourrez générer l'adresse SIP à l'étape suivante.

2

Générer l'adresse SIP

Depuis l'interface de génération du service, choisissez la plateforme cible et renseignez le nom ou l'identifiant de la réunion.

Vous obtenez ensuite un format de liaison SIP adapté à la conférence à rejoindre.

Exemple : sip:[numero_plateforme].[numero_conference]@votre-domaine.example

3

Rejoindre la réunion depuis la salle

Option A : appel direct de la réunion

  • sip:[numero_plateforme].[numero_de_conférence]@service.example
  • ou sip:[numero_plateforme].[numero_de_conférence]@votre-domaine.example

Option B : appel via menu interactif

  1. Appeler : sip:9@votre-domaine.example
  2. Sélectionner la plateforme puis entrer le numéro de la conférence.

Option B bis : appel via menu interactif et QR code

  1. Appeler : sip:9@votre-domaine.example
  2. Scanner le QR code affiché (ou aller sur service.example), qui renvoie vers une page de contrôle à distance permettant de :
    • sélectionner la plateforme
    • renseigner le nom de la réunion et le nom d'affichage de la salle
    • interagir avec l'UI en cours de réunion

Cette option permet de se passer de l'étape 2 (génération de l'adresse SIP) : la réunion peut être renseignée directement depuis l'interface web ou depuis la page de contrôle associée au QR code.

4

Interagir pendant la réunion

Une fois connecté, appuyer sur # pour afficher le menu.

Fonctions disponibles :

  • lever la main
  • changer l'affichage
  • afficher le chat
  • voir les participants
5

Partager du contenu

Le partage de contenu est supporté via BFCP (présentation), généralement exposé sur les équipements via une entrée HDMI/VGA.

Limitations connues

  • Impossible de démarrer une conférence via le connecteur
  • La réunion doit exister et être active

Compatibilité

Compatible avec les équipements SIP (RFC 3261), validé avec :

Polycom Cisco Huawei Aver

Configuration de votre équipement

Activer le protocole SIP

Pour connecter votre équipement, vous devez le régler pour utiliser le protocole SIP (RFC 3261) lors de son appel vers le connecteur de salle. Veuillez vous référer à la notice de votre équipement ou à votre intégrateur visio pour réaliser cette configuration.

Ajouter le connecteur au carnet d'adresses de l'équipement

Pour faciliter l'utilisation des connecteurs de salle SIPMediaGW, vous pouvez enregistrer le numéro du menu interactif dans le carnet d'adresses de votre équipement.

  • sip:9@votre-domaine.example
  • ou bien sip:9@service.example si votre équipement ne résout pas les noms de domaine

Assurer la réception des flux média

Afin de pouvoir communiquer, un équipement de visioconférence doit être correctement configuré pour recevoir les flux audio et vidéo. La configuration exacte dépend de votre environnement réseau et de votre matériel.

  • Attribuer une adresse publique à votre équipement.
  • Mettre en place un NAT explicite entre l'adresse de votre équipement et une adresse publique.

Bonnes pratiques réseau

Pour que les appels vidéo vers les connecteurs de salle SIP se déroulent correctement, il est important que les règles de sécurité et de réseau de votre environnement autorisent le trafic SIP et les flux multimédias attendus.

Exemples de configuration

  • Adresse SIP de service : sip:9@votre-domaine.example
  • Adresse publique d'accès : 203.0.113.10
  • Nom de domaine de service : service.example

Protocoles et ports courants

Vers les serveurs SIP :

PortTransportApplication
5060tcpSIP
5060udpSIP
5061tcpSIP/TLS

Pour les flux multimédias vers les serveurs de transit :

PortTransportApplication
40000-49999udprtp, rtcp, bfcp
